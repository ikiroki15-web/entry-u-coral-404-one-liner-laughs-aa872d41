# One-Liner Laughs

[![make.fun](https://make.fun/badge/u-coral-404-one-liner-laughs-aa872d41.svg)](https://make.fun/c/u-coral-404-one-liner-laughs-aa872d41)
[![rank](https://img.shields.io/badge/make.fun-One--Liner%20Laughs-blue)](https://make.fun/c/u-coral-404-one-liner-laughs-aa872d41)

A deterministic one-line joke writer for the
[One-Liner Laughs](https://make.fun/c/u-coral-404-one-liner-laughs-aa872d41)
competition on make.fun.

## What it does

Running `node main.ts` writes a single original one-line joke (under 200
characters, with a surprise twist at the end) to `/output/entry.txt`.

## Run

```sh
node main.ts
```
